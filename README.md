# 🔍 Lost and Found

A full stack web application that helps users report and find lost items in their community.

## 🚀 Features

- 📋 Report lost or found items with descriptions and photos
- 🔎 Search and filter items by category, location, or date
- 🔐 User authentication (register / login)
- 📬 Contact the item reporter directly
- 📱 Responsive design for mobile and desktop

## 🛠️ Tech Stack

**Frontend:** React, CSS  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**Auth:** JWT (JSON Web Tokens)  
**Tools:** Postman, Git

## ⚙️ Installation

```bash
# Clone the repository
git clone https://github.com/Sighassenk/LostAndFound.git
cd LostAndFound

# Install backend dependencies
cd backend
npm install

# Install frontend dependencies
cd ../frontend
npm install
```

## ▶️ Running the App

```bash
# Start the backend (from /backend)
npm start

# Start the frontend (from /frontend)
npm start
```

> Make sure MongoDB is running locally or set your `MONGO_URI` in a `.env` file.
